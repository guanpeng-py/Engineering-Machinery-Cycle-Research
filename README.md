# 工程机械行业周期性特征研究 (Engineering Machinery Cycle Research)

## 📖 项目简介
本项目基于 2018 年 1 月至 2025 年 12 月的月度数据，探究工程机械行业（以挖掘机国内销量为核心指标）的周期波动特征。重点分析该行业与宏观需求指标（房屋新开工面积、基础设施投资）之间的联动关系与驱动逻辑切换。

## 🗂 数据来源
- **挖掘机国内销量**：中国工程机械工业协会（手动整理，含单月及累计数据）。
- **房屋新开工面积、基础设施投资**：国家统计局（累计同比口径）。
- *样本期*：2018年2月 - 2025年12月（共88个月，剔除每年1月免报期）。

## 🔍 分析框架
1. **数据清洗与口径对齐**：处理春节等季节性扰动，将挖掘机单月销量转换为累计同比，并与宏观数据完成时间轴对齐。
2. **周期阶段划分**：基于连续3个月累计同比的边际变化方向，划分“上行期”、“下行期”与“过渡期”。
3. **驱动因素与悖论验证**：对比全样本与分阶段（2018-2021 vs 2022-2025）的相关系数，揭示驱动逻辑的结构性突变（辛普森悖论）。
4. **领先/滞后检验**：运用交叉相关函数（CCF）与稳健性检验，判定工程机械销量与宏观指标的时间同步性。

## 💡 核心发现
- **高弹性特征**：挖掘机销量累计同比波动率（标准差 39.64）显著高于新开工（19.09）和基建投资（7.57）。
- **驱动逻辑切换与辛普森悖论**：全样本中挖机与新开工强相关（r=0.772），但分阶段看，2022年地产暴雷后，基建虽逆势托底，挖机与基建却转为强负相关（-0.695）。这证实了基建托底无法对冲地产下行对通用设备的拖累，地产新开工是核心驱动力。
- **同步指标属性**：CCF 检验显示相关系数均在 lag=0 处达到峰值，工程机械销量是宏观经济的**同步指标**，而非预测性先行指标。

## ⚙️ 如何运行
1. 确保已安装 `pandas`, `numpy`, `matplotlib`, `seaborn`。
2. 进入 `notebooks/` 目录，打开并运行 `01_engineering_cycle_analysis.ipynb`。
3. 所有图表与结果表格将自动保存至 `output/` 目录下。

## ⚠️ 局限性
- 样本期未能完全覆盖完整的 8-10 年朱格拉周期；
- 未纳入设备存量更新及出口数据（这两项可能是 2024-2025 年销量逆势复苏的潜在驱动力）。
